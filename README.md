# Verbos irregulares 1

Web estática (HTML + JS, sin build). El progreso se guarda en el navegador y la web funciona sin conexión (PWA).

## Desplegar en Vercel

**Opción A: GitHub**
1. Sube esta carpeta a un repositorio.
2. En vercel.com/new importa el repositorio.
3. Framework Preset: **Other**. Deja vacíos Build Command y Output Directory. Pulsa Deploy.

**Opción B: terminal**
```
npm i -g vercel
cd verbos-vercel
vercel --prod
```
